# Дизайн-код CarUnity

Единые правила внешнего вида сайта. Каждая секция, которую мы переделываем, приводится к этим
правилам; старые секции переходят на них постепенно (статус — в конце файла).

Сайт **только тёмный**. Светлая тема отключена, поэтому в переделанном коде нет классов
`bg-white`, `dark:…` и прочих «светлых» вариантов.

## 1. Цвета (токены)

Цвета задаются один раз в `src/index.css` (переменные `--cu-*`) и доступны в Tailwind по смыслу,
а не по оттенку. Писать `bg-[#1b1b22]`, `bg-slate-900`, `text-emerald-400` в новых секциях нельзя.

| Токен | Цвет | Где |
|---|---|---|
| `bg-page` | #101014 | фон страницы |
| `bg-surface` | #1b1b22 | карточки, панели, шапка, выпадающие меню |
| `bg-raised` | #2a2b33 | поля ввода, чипсы, второстепенные кнопки |
| `border-line` | #292a32 | рамки и разделители |
| `text-ink` | #fafafa | основной текст |
| `text-ink-2` | #c7c7cf | второстепенный текст, пункты меню |
| `text-ink-3` | #9a9aa5 | подсказки, подписи. Темнее для текста не используем |
| `bg-brand` / `hover:bg-brand-hover` | #10b981 / #059669 | главная кнопка блока, активное состояние |
| `text-brand-text` | #34d399 | зелёный текст и иконки на тёмном |
| `electric` | #465a90 | акцент электромобилей (сейчас выключен) |

**Слоёв только два: страница (`page`) и карточка (`surface`).** Карточки не кладём внутрь
рамки-секции: заголовок секции стоит прямо на странице. Карточка темнее своего фона
читается как «дырка» — так не делаем. Фото машин всегда горизонтальные (4:3 или 16:9).

Прозрачность — через модификатор: `bg-brand/15` (подсветка выбранного), `bg-surface/80`.

## 2. Скругления

| Класс | Радиус | Что |
|---|---|---|
| `rounded-lg` | 8px | чипсы, маленькие кнопки (h-8), пункты меню |
| `rounded-xl` | 12px | кнопки, поля, карточки внутри секции |
| `rounded-2xl` | 16px | секция (`Panel`) |
| `rounded-full` | — | аватары, точки-индикаторы |

## 3. Текст

Шрифт Roboto. Шкала: 12 (`text-xs`, подписи) · 14 (`text-sm`, основной) · 16 (`text-base`) ·
18 (`text-lg`, заголовок карточки и секции) · 24 (`text-2xl`, цена, заголовок страницы).
**Меньше 12px не бывает.** Произвольные размеры (`text-[13px]`) не используем.

## 4. Размеры элементов

- Поле и обычная кнопка — **40px** (`h-10`). Главная кнопка формы — 44px (`size="lg"`).
  Маленькая кнопка — 32px (`size="sm"`). Иконка-кнопка — 40×40.
- Отступ от края страницы: 16px на телефоне, 24px от 640px (`Container`).
- Ширина контента — `max-w-7xl` (1280px).
- Внутренний отступ секции: 16px, на ПК 20px (`Panel`).
- Промежутки: 8px между полями, 12–16px между карточками и секциями.

## 5. Готовые блоки (`src/components/ds`)

| Блок | Назначение |
|---|---|
| `Container` | ширина страницы и боковые отступы |
| `Panel` | секция-карточка с необязательным заголовком |
| `Chip` | факт об объявлении: иконка + значение (пробег, мощность…) |
| `fieldClass` | классы любого поля: select, input |
| `navLinkClass` | ссылка в шапке и меню |

Кнопки — только `Button` из `src/components/ui/button.jsx`:
`default` (зелёная, одна на блок), `secondary`, `ghost`, `outline`, `link`.

## 6. Рекламный баннер главной (слот `hero-main`)

От края до края, фиксированная высота: телефон 2:1 (без перекрытия), планшет 280px,
ПК 460px — нижние 96px на ПК закрывает панель поиска.
Вкладки типа транспорта стоят над левым верхним краем панели поиска (отдельный элемент,
активная вкладка сливается с панелью). Фильтры короткие: одна строка, остальное — «Все фильтры».

Рекламодатель даёт две картинки: **2560×640** (ПК и планшет) и **750×375** (телефон).
Логотип и текст — в центральной зоне ~1200×300 в верхней части широкой картинки:
края обрезаются на узких экранах, низ перекрыт поиском.

## 7. Правила логики

1. Одна и та же вещь выглядит одинаково везде: карточка объявления в сетке — всегда
   `CompactCarCard` (исходная версия: название и цена в строке, комплектация, «пиллсы» с
   тех. данными — её берём за основу), числа — через `formatPrice` / `formatNumber`.
2. Один источник данных на блок. Никаких id объявлений, вписанных в код.
3. Нет мёртвого кода: никаких `{false && …}`, неиспользуемых состояний и импортов —
   выключенное удаляется (история есть в git).
4. Переходы внутри сайта — через роутер (`Link`, `navigate`), без перезагрузки страницы.
5. Списки ссылок и пунктов описываются массивом и рисуются одним циклом, а не копиями разметки.
6. Секция страницы — отдельный компонент; файл страницы только собирает секции.
