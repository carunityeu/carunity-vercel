# Отвязка от Base44: план и статус

Цель — в коде не остаётся ни одного обращения к Base44 (SDK, плагин, файлы, домены).
Карта старой системы — [ARCHITECTURE.md](ARCHITECTURE.md), новая база — [../supabase/README.md](../supabase/README.md).

## Статус по слоям

| # | Слой | Где в коде | Чем заменяем | Статус |
|---|------|-----------|--------------|--------|
| 1 | Данные (`base44.entities.*`, 269 вызовов в 78 файлах) | весь `src` | `src/api/entities.js` → Supabase (PostgREST), тот же интерфейс | ✅ готово |
| 2 | Вход и профиль (`base44.auth.*`, 35 файлов) | `lib/AuthContext.jsx`, Login/Register/Reset/Mfa, Header, кабинеты | Supabase Auth: email+пароль, Google, сброс пароля, OTP | ⏳ нужен экспорт **User** |
| 3 | Файлы (`UploadFile`/`UploadPublicFile`, 18 вызовов) | формы объявлений, аватар, документы дилера | Supabase Storage (бакеты `listings`, `avatars`, `private`) | ⏳ |
| 4 | Серверные функции (`base44.functions.invoke`, 17 вызовов, 28 функций в `base44/functions`) | оплата, лиды, рейтинг цены, импорт по ссылке, письма | Vercel Functions (`/api/*`) с service-role ключом | ⏳ |
| 5 | AI (`InvokeLLM` ×9, агент Caro ×3 файла) | Caro, сравнение, перевод сообщений, помощник | `/api/ai/*` → Claude API, ключ только на сервере | ⏳ |

| 7 | Расписание (7 workflows) | истечение объявлений и премиума, сохранённые поиски, падение просмотров, новости | Vercel Cron → `/api/cron/*` | ⏳ |
| 8 | Картинки на `media.base44.com` (60 ссылок в коде + фото объявлений) | иконки, фавикон, og:image, фото | `public/` для иконок; фото — в Supabase Storage скриптом | ⏳ |
| 9 | Сборка | `@base44/vite-plugin`, `@base44/sdk`, `lib/app-params.js`, `base44Client.js` | убрать после слоёв 2–8 | ⏳ последним |
| 10 | Папка `base44/` | определения сущностей, функций, писем | перенести нужное в `supabase/` и `api/`, папку удалить | ⏳ последним |

## Порядок
1. **Вход (слой 2).** Без него не работают кабинет, избранное, сообщения и создание объявлений.
   Пароли из Base44 не выгружаются: пользователи создаются в Supabase Auth по email из экспорта,
   при первом входе — «Забыли пароль?» или вход через Google по тому же email.
2. **Файлы (слой 3)** — чтобы можно было подавать объявления с фото.
3. **Оплата** (`createCheckoutSession`, `stripeWebhook`, `renewListing`) — переносим вместе:
   активация и премиум ставятся только сервером (права в базе уже так настроены).
4. **Сообщения, уведомления, лиды** (`notifyDealerNewLead`, `sendContactEmail`, `translateMessage`).
5. **Расписание (слой 7)**, включая снятие истёкшего премиума (сейчас флаг не снимается).
6. **AI и Caro (слой 5)**, кабинет дилера, Meta Ads.
7. **Картинки и чистка (слои 8–10)**, удаление SDK и плагина.

Каждый шаг: ветка → тестовая версия Vercel → проверка → main.

## Что нужно от владельца
- Экспорт **User** (для шага 1), затем Dealer, Favorite, Message, Notification и остальные.
- Новые миграции в `supabase/migrations` выполнять в SQL Editor по мере появления
  (сейчас: `20261123000003_realtime.sql` — живые обновления чата и уведомлений).
- Ключи сервисов (Stripe, Resend, Claude API, service-role Supabase) — только в переменных Vercel, не в чат.
