# Supabase: новая база CarUnity

Замена бэкенда Base44. Карта старого проекта — в [../docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).

## Что здесь
- `migrations/20261122000001_schema.sql` — 39 таблиц. **Генерируется** из `base44/entities`
  командой `npm run db:schema`, руками не правим.
- `migrations/20261122000002_auth_and_rls.sql` — профили пользователей, защищённые поля,
  служебные функции и права доступа (RLS) на каждую таблицу.
- `tests/rls-test.mjs` — поднимает Postgres в памяти (PGlite), применяет миграции и проверяет
  права доступа. Запуск: `npm run db:test`.

## Ключевые решения
- **ID записей из Base44 сохраняются** (`id text`). Связи между таблицами и старые ссылки
  (`/CarDetails?id=…`) продолжают работать после переноса.
- Служебные поля как в Base44: `created_date`, `updated_date`, `created_by` (email), `created_by_id`.
  Их заполняет база, а не браузер.
- Пользователь — это `auth.users` (Supabase Auth) плюс `public.profiles` (поля бывшей сущности User,
  а также `role` и `legacy_id` = старый ID из Base44). Профиль создаётся автоматически при регистрации.
- Публичные данные о человеке (имя, аватар, город) отдаёт представление `public_profiles`.
  Таблица `profiles` видна только самому пользователю и админам.
- Защищённые поля меняют только сервер и админы: продвижение и счётчик просмотров объявлений,
  активация неоплаченного объявления, подписка и верификация дилера, роль пользователя.
- Просмотры считаются через `increment_listing_views()`, оценка модели — через `rate_model()`.
- Пока **не включены**: проверки допустимых значений (enum) и обязательных полей, внешние ключи.
  Добавим после импорта, когда увидим реальные данные.

## Временные послабления (TEMP в миграции)
Эти потоки пока работают в браузере и будут перенесены на сервер:
- создание объявления само решает, «бесплатно → active» или «платно → pending»;
- уведомления другим пользователям (быстрая продажа, рефералы) создаются из браузера;
- реферальная программа. Начисление бонусных дней дилеру из браузера **заблокировано**:
  раньше так любой мог продлить подписку любому салону. Бонусы вернутся серверной функцией.
